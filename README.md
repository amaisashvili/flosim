# FLŌSim

FLŌSim (Free, Libre, Open SIMulations) is an Excel add-in for
statistical simulations. It runs in desktop
Microsoft Excel on Windows and Mac.

[Download the add-in](https://github.com/amaisashvili/flosim/raw/refs/heads/main/flosim.xlam) ·
[Installation guide](flosim_installation_guide.pdf) ·
[User documentation](documentation/)

## What you can do

- Run Latin Hypercube or Monte Carlo simulations directly from an Excel model.
- Fit probability distributions to historical observations and model
  dependence between inputs such as prices and yields.
- Compare scenarios and visualize results with density, cumulative
  distribution, and stoplight charts.

## Questions and bug reports

[Open a GitHub issue](https://github.com/amaisashvili/flosim/issues).
For a bug, include your Excel version, operating system, and the
smallest formula or workbook that reproduces it.
